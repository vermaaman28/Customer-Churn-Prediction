# Customer Churn Prediction

## Overview
This project analyzes telecom customer data to identify factors contributing to customer churn and builds machine learning models to predict churn.

## Dataset
- 7032 customers
- 31 features
- Telecom industry dataset

## Key Findings
- Month-to-month contracts have the highest churn rates.
- Customers with shorter tenure are more likely to churn.
- Higher monthly charges are associated with increased churn.
- Long-term contracts improve retention.

## Models Used

| Model | Accuracy |
|---------|---------:|
| Logistic Regression | 78.75% |
| XGBoost | 80.03% |

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- XGBoost

## Business Recommendations
- Promote long-term contracts.
- Improve onboarding for new customers.
- Offer retention incentives to high-value customers.
- Bundle support and security services.

## Project Outcome
The project successfully identified major factors influencing customer churn and developed predictive models capable of helping businesses proactively retain at-risk customers.
